# 軽量化バッチ

商品マスタ（軽量化済み）を作り、サーバーへ送ります。PowerShell 5.1（`powershell.exe`）で動かします。7（`pwsh.exe`）でも動きますが、本番のタスクスケジューラは 5.1 です。

基幹システムから毎日届くのは**差分**（追加・変更された商品×店舗の行だけ。削除は届かない）です。そのためバッチは作業フォルダに「現在のマスタ」（`pop-master.csv`）を持ち、初回だけ商品台帳から作り、以後は差分を当てて更新します。

## モード

| モード | 実行方法 | 内容 |
| --- | --- | --- |
| 初回変換 | `-Init` | 商品台帳から現在のマスタを作る。作り直しの元として `pop-master.base.csv` も残す |
| 通常 | オプションなし | 差分を保管し、現在のマスタに当てる |
| 作り直し | `-Rebuild` | `pop-master.base.csv` に、保管した差分を古い順にすべて当て直す |

どのモードも、最後に現在のマスタを `PUT /api/admin/master` に送ります。前回送った内容と同じなら送りません。

## 価格の決め方

| 項目 | 決め方 |
| --- | --- |
| 標準価格（I 行） | 商品台帳の定番売価１。無ければ空。**差分では変わらない**（差分に定番売価１が無いため） |
| 店舗の価格（P 行） | 商品台帳の枠2〜99と、差分の各行。標準価格と同じ価格の店舗は持たない。同じ価格の店舗は `7711\|7719` のように1行にまとめる |

差分に新しく出てきた商品は、標準価格が空になり、差分に載った店舗だけに価格があります。標準価格も店舗の価格も無い店舗では、画面で 0 円になります。

## 初回変換（-Init）

商品台帳（Shift-JIS・見出し付き・1行＝1商品）を読みます。列は見出しの名前で探すので、列の並びが変わっても動きます。原単価の列は読まないので、事前に削除する必要はありません。

| マスタの項目 | 商品台帳の列 | 扱い |
| --- | --- | --- |
| jan | 商品コード | 13桁の 0 埋め。先頭が 0 5つなら下8桁（EAN-8）にする。8・12・13桁の数字でなければ除外 |
| 標準価格 | 定番売価１ | 空なら空。数字でなければ空にしてログに出す。税込は「税抜 × 税率の切り捨て」で計算 |
| taxRate | 税率コード | 1 → 10、2 → 8。それ以外の商品は除外 |
| maker / name / qty1 / qty2 / comment | POP用メーカ / POP用商品名 / POP用かおり（規格） / POP用容量（規格） / POP用コメント | 空なら空のまま。「,」は「，」に置き換える |
| risk | 改正薬事区分 | 下の表で名前にする。表に無い値は空にしてログに出す |
| 店舗の価格 | 店舗コード２〜９９・定番売価２〜９９ | 店舗コードが空の枠は無視（以前の店舗の名残）。`\|` 区切りの店舗にはそれぞれ同じ価格。同じ店舗が複数の枠にあれば後の枠を採用 |

店舗コード１は無視します。基本売単価・基本価格（税込）・発注終了日・発注停止フラグは使いません（発注を終えた商品も含める）。

| 改正薬事区分 | 医薬品区分 |
| --- | --- |
| 0（00） | 通常商品（画面では表示しない） |
| 1 | 第1類医薬品 |
| 2 | 指定第2類医薬品 |
| 3 | 第2類医薬品 |
| 4 | 第3類医薬品 |
| 9 | 要指導医薬品 |
| 10 | 医療用医薬品 |

商品台帳は一部の値が「"」で囲まれている（カナ名称にタブを含む行など）ため、「"」を含む行だけ引用符を解釈して読みます。列数が見出しと違う行があれば中止します。

処理時間の目安は 20万行で数分です。現在のマスタが既にあると中止するので、やり直すときは `-Force` を付けます。

**商品台帳は Excel で開いて保存しないでください。** 商品コードが「4.9E+12」のような指数表記になったり、先頭の 0 が消えたりして、元に戻せなくなります。

## 通常実行（差分）

1. 差分（`InputPath`）が無ければ何もしない
2. 差分を作業フォルダの `incoming\` に写す（処理中に上書きされても困らないように）。基幹システムが書き込み中で写せなければエラー（次回の実行で処理される）
3. 前回当てた差分とハッシュが同じなら「新しい差分なし」として当てない
4. 新しい差分なら、`diffs\` に zip で保管する。名前は `POPSYOHIN_<差分の更新日時>_<ハッシュの先頭8文字>.zip` で、名前順が更新日時順になる。同じ内容の差分が既にあれば保管しない
5. 全行を検査する。「"」を含む行・列数が27でない行が1つでもあれば中止（現在のマスタは変えない）。JAN（8/12/13桁の数字）・店舗コード・価格が不正な行は除外し、件数と行番号をログに出す
6. 現在のマスタに当てる
   - 差分に出てきた商品の共通項目（税率・メーカー・商品名・数量1・数量2・コメント・医薬品区分）は差分の値で上書きする（店舗によって違えば、最初の行を採用）
   - 差分に出てきた店舗の価格は差分の値にする。標準価格と同じなら、その店舗の P 行は無くなる
   - 医薬品区分の全角数字は半角にする（「第２類医薬品」→「第2類医薬品」）
   - マスタに無い商品は、標準価格を空にして追加する
7. 書き出して、送る（前回送った内容と違うときだけ）

同じ差分を2回当てても結果は変わりません。逆に、取りこぼした差分は二度と手に入らないので、**タスクスケジューラは1時間ごとなど何度も実行する**設定にしてください。新しい差分が無ければすぐ終わります。

送信に失敗しても、現在のマスタは更新済みのままです。次回の実行で、前回送った内容と違うことを検出して送り直します。送信の失敗時は30秒おきに最大3回やり直し、認証エラーや内容の問題はすぐ止めます。サーバーの `{"ok":true}` を確認して成功とします。

## 作り直し（-Rebuild）

`pop-master.base.csv` を読み、`diffs\` の zip を名前順（古い順）にすべて当て直して、現在のマスタにします。現在のマスタが壊れた・消えたとき、当て方のルールを変えたときに使います。

商品台帳より古い差分を当てると、新しい価格が古い価格で上書きされます。初回変換のときに `diffs\` に zip があれば警告を出すので、商品台帳より古いものは削除してください。商品台帳と差分の切り替えのタイミングは、本番稼働までに決めます。

## 入力ファイルのレイアウト

### 差分（POPSYOHIN.CSV。Shift-JIS・見出し無し・27列・1行＝1店舗×1商品）

| 列番号（0始まり） | 列名 | 使い方 |
| --- | --- | --- |
| 2 | 店舗コード | 店舗番号 |
| 4 | スキャニングコード | JAN |
| 7 | 税率 | 税率（%） |
| 10 / 11 | 売単価(税抜) / 売単価(税込) | 店舗の価格 |
| 20 | POP用メーカー名 | メーカー |
| 21 | POP用商品名 | 商品名 |
| 22 | POP用規格名 | 数量1 |
| 23 | 自由入力欄1 | 数量2 |
| 24 | 自由入力欄2 | コメント |
| 25 | 自由入力欄3 | 医薬品区分（医薬品以外は「通常商品」） |

値の前後の空白（全角を含む）は取り除きます。列の位置はスクリプト冒頭の `$COL_*`、商品台帳の列名は `$LEDGER_*` で変えられます。

## 使い方

| 実行のしかた | 用途 |
| --- | --- |
| `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<パス>\pop-master-batch.ps1"` | 通常の実行（タスクスケジューラに登録する形） |
| 上に `-Init` | 初回変換。商品台帳のパスは設定ファイルの `LedgerPath` |
| 上に `-Rebuild` | 作り直し |
| 上に `-NoUpload` | 変換・差分の適用だけ行い、送らない（動作確認用。どのモードとも組み合わせられる） |
| 上に `-Force` | `-Init` では現在のマスタがあっても作り直す。それ以外では前回と同じ内容でも送る |
| 上に `-SaveToken` | アップロード用トークンを保存する（初回・入れ替え時） |

- `-ExecutionPolicy Bypass` はその1回の実行だけ制限を外す。PC の実行ポリシーは変えない
- トークンは Windows の DPAPI で暗号化して作業フォルダの `upload-token.dat` に保存する。**保存した Windows ユーザー・その PC でしか読めない**ため、タスクスケジューラも同じユーザーで実行する
- 右クリックの「PowerShell で実行」は使わない（終了と同時に画面が閉じ、オプションも付けられない）。手動で動かすときはターミナルか .bat から実行する

## 設定ファイル（pop-master-config.psd1）

| キー | 内容 |
| --- | --- |
| InputPath | 差分（POPSYOHIN.CSV）のパス |
| LedgerPath | 商品台帳のパス（`-Init` でだけ使う） |
| WorkDir | 作業フォルダ |
| UploadUrl | 送り先（`/api/admin/master`） |

## 作業フォルダ（`WorkDir`）のファイル

| ファイル | 内容 |
| --- | --- |
| pop-master.csv | 現在のマスタ（これを送る） |
| pop-master.prev.csv | 1つ前の現在のマスタ |
| pop-master.base.csv | 初回変換の結果（作り直しの元。消さない） |
| diffs\POPSYOHIN_*.zip | 保管した差分（作り直しに使う。消さない） |
| incoming\POPSYOHIN.CSV | 処理中の差分の写し（作業用） |
| state.json | 最後に当てた差分のハッシュ・最後に送ったマスタのハッシュと日時 |
| upload-token.dat | 暗号化したトークン |
| logs\pop-master-YYYYMMDD.log | ログ（90日で自動削除） |

作業フォルダは、店舗スタッフが触れない場所にしてください。`pop-master.base.csv` と `diffs\` は、作業フォルダごと定期的に別の場所へバックアップすることをお勧めします。
